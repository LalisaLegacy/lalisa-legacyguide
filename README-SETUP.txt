# LALISALEGACY — lalisa-legacyguide.com

This folder is ready for GitHub Pages.

1. Create a GitHub repository (a public repository is available with GitHub Free).
2. Upload every file in this folder to the repository root.
3. In the repository: Settings -> Pages.
4. Choose GitHub Pages and publish from the branch containing index.html.
5. Add the custom domain:
   lalisa-legacyguide.com
6. At your domain registrar, add the DNS records GitHub gives you.
7. Keep the CNAME file in the repository.
8. Once DNS finishes propagating, enable HTTPS.

The website is static HTML/CSS/JavaScript and does not need a build command.
